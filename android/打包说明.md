# 宿舍账本 · Android App 打包说明

把网页版「宿舍账本」用 **原生 Java + WebView 壳** 打包成 Android App。

> 说明：外壳采用纯 Java（不引入 Kotlin 插件），依赖仅 `androidx.appcompat` + `androidx.core`，
> 全部为常见稳定版本，**离线环境也能直接构建**。工程已自带 `gradle-wrapper.jar`，无需首次生成。

- **不改动任何网页业务逻辑**：算法、计算规则、数据结构、localStorage key（`dorm-ledger:v1`）、导出 JSON 结构全部保持原样。
- 只新增两层：
  1. **Android 外壳**（本 `android/` 目录）：WebView 容器 + 移动端能力补全；
  2. **网页端的适配层**：`index.html` 里新增的一小段「安全区/键盘 CSS」和「原生桥接 `<script>`」，**在普通浏览器里会自动空跑**，不影响原有网页。

| 项目 | 要求 |

## 三、运行与打包

### 3.1 直接运行
用 Android Studio 打开 `android/`，连接真机或启动模拟器，点 ▶ Run 即可。

### 3.2 生成调试 APK
```bash
cd android
./gradlew assembleDebug      # Windows: gradlew.bat assembleDebug
# 产物：app/build/outputs/apk/debug/app-debug.apk
```

### 3.3 生成正式签名 APK

**第 1 步：创建签名密钥库（只需一次）**
```bash
keytool -genkeypair -v -keystore dormledger.jks -alias dormledger \
  -keyalg RSA -keysize 2048 -validity 10000
```
按提示设置密码（务必记住）、姓名等信息。

**第 2 步：配置签名（二选一）**

- **推荐：在 Android Studio 里配**
  `Build → Generate Signed App Bundle / APK → APK → Create new…` 选择上一步的 `dormledger.jks`，
  按向导完成后，AS 会生成签名 APK 到 `app/release/`。

- **或写进 `app/build.gradle`**（把密码放在 `keystore.properties` 并加入 `.gitignore`）：
  ```groovy
  android {
      signingConfigs {
          release {
              storeFile file("../dormledger.jks")
              storePassword "你的密码"
              keyAlias "dormledger"
              keyPassword "你的密码"
          }
      }
      buildTypes {
          release { signingConfig signingConfigs.release }
      }
  }
  ```

**第 3 步：构建**
```bash
./gradlew assembleRelease
# 产物：app/build/outputs/apk/release/app-release.apk
```

**第 4 步：安装到手机**
```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```
或把 APK 传到手机点击安装（需允许「未知来源应用」）。

### 关于 Android 13+（API 33）媒体权限
系统文件选择器（SAF / `ACTION_GET_CONTENT`）会为所选 URI 授予**临时读权限**，
原生侧无需 `READ_MEDIA_IMAGES` 也能读取，因此**不会**因权限缺失崩溃。
Manifest 中声明 `READ_MEDIA_IMAGES` 仅为兼容个别定制系统在读取媒体时的严格校验；
原生侧所有文件读写都做了 `try/catch` 兜底，即使权限被拒也只是提示失败，不会崩溃。

### 关于数据持久化与备份
- `localStorage` 保存在应用私有目录，**App 不卸载、不清数据就不会丢**。
- 导出的备份文件会同时写到：
  - 公共「下载」目录：`下载/宿舍账本/宿舍账本备份-YYYY-MM-DD.json`（API 29+ 无需权限）；
  - 应用私有目录：`files/exports/`（用于系统分享，通过 FileProvider 以 `content://` 分享给微信/QQ）。
- 换机时：旧机「导出备份」→ 分享或拷贝 JSON → 新机「导入备份」。

## 五、网页端改动清单（可核对）

`index.html` 相对原版只做了三处**附加**改动，业务 JS 一行未改：

1. `<meta name="viewport">` 增加 `viewport-fit=cover`（`env(safe-area-inset-*)` 在 Android WebView 生效的前提）。
2. `<style>` 末尾新增一段「移动端 / Android WebView 适配」CSS（安全区变量、键盘态 `html.kb-open`、弹层与 Toast 避让）。
3. `</body>` 前新增一段「Android WebView 原生桥接」`<script>`：仅在 `window.AndroidBridge` 存在时生效，负责导出落盘、剪贴板、安全区/键盘尺寸传递、返回键弹层判断。

> 同步关系：`index.html`、`deploy/index.html`、`android/app/src/main/assets/index.html` 三者**内容完全一致**。
> 每次修改网页后，需重新复制到 `assets/` 与 `deploy/`，否则 App 内看到的仍是旧版。

## 六、常见问题

| 问题 | 排查 |
| --- | --- |
| 打开工程报 `gradle-wrapper.jar` 缺失 | 工程已自带该文件；若丢失，在 `android/` 执行 `gradle wrapper --gradle-version 8.2.1` 重新生成 |
| 同步失败提示 SDK 未安装 | `Tools → SDK Manager` 安装 Android 34 Platform + Build-Tools |
| App 里数据没保存 | 确认 `android:name` 未删、`domStorageEnabled` 为 `true`；用 `chrome://inspect` 查看 WebView 控制台 |
| 导出后没弹分享 | 部分 ROM 需在「设置 → 应用 → 权限」里允许本 App 存储/文件权限；API 29+ 无需权限 |
| 想调试网页 | 手机开 USB 调试，电脑 Chrome 访问 `chrome://inspect`，可直接调试 assets 页面 |
| 想改 App 名称/图标 | 改 `res/values/strings.xml` 的 `app_name`；图标改 `res/drawable/ic_launcher_foreground.xml`（及 `_background`） |
| 想支持横屏 | 删除 `AndroidManifest.xml` 里的 `android:screenOrientation="portrait"`（`configChanges` 已含 `orientation`，不会重建） |
